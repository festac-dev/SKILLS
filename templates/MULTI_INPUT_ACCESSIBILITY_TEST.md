- [ ] No essential hover-only action.
- [ ] Keyboard focus is visible and logical.
- [ ] Focus is restored after dialogs/navigation.
- [ ] Touch targets and spacing are usable.
- [ ] Screen-reader names, roles, values, and announcements are meaningful.
- [ ] Gestures have alternatives.
- [ ] Increased text size and zoom remain usable.
- [ ] Status is not conveyed by color alone.
- [ ] Reduced motion is respected.
- [ ] Remote/controller navigation works if supported.
