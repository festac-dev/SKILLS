# Playbook: Elevate Any Project to Stand Out

1. **Audit what exists** — strengths, identity, constraints, performance, accessibility, content quality. Preserve what is good and what the user decided.
2. **Find the essence** — one-sentence truth about the product and its users.
3. **Locate generic moments** — template layouts, stock imagery, vague copy, default components, empty states, errors, onboarding.
4. **Pick leverage points** — the 3–5 places where improvement most changes perception and outcomes (first impression, core interaction, trust moments, speed, content).
5. **Design a signature moment** — purposeful, fast, accessible (see `references/standout-project-patterns.md`).
6. **Raise the floor** — typography, spacing, states, responsive behavior, keyboard/focus, copy, performance budgets.
7. **Add depth where valuable** — interactive demos, real data visualization, animated explanations, sandbox playgrounds.
8. **Engineer trust** — reliability, privacy, honest claims, status, docs.
9. **Verify** — real devices, assistive tech, reduced motion, slow network; gather user feedback when possible.
10. **Report** — what changed, why, evidence, what was intentionally left alone.
