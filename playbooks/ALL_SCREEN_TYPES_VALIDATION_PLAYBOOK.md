# All-Screen-Types Validation Playbook

1. Research where users work, device classes, viewing distance, input methods, connectivity, and environment.
2. Select primary, supported, best-effort, and unsupported targets with reasons.
3. Define content-driven responsive rules and intentional large-screen layouts.
4. Specify orientation, resize, split-screen, fold/unfold, safe-area, and virtual-keyboard behavior where applicable.
5. Test relevant touch, keyboard, pointer, stylus, remote, controller, voice, switch, and assistive inputs.
6. Test compact, intermediate, expanded, high-density, ultrawide, zoomed, and large-text conditions.
7. Validate TV, kiosk, wearable, automotive, industrial, e-ink, embedded, and spatial targets on real hardware when claimed.
8. Complete critical user journeys; inspect clipping, overflow, focus, readability, state preservation, performance, and recovery.
9. Publish the coverage matrix, evidence, limitations, and unsupported targets.

A responsive screenshot is not proof of complete compatibility.
