# Playbook: Adapt the System to Any Project Type

1. Identify project type(s) using `references/project-type-starter-profiles.md`; projects often combine several.
2. Run `orchestrator/PROJECT_DISCOVERY_PROTOCOL.md` on the real repo/brief.
3. Use `orchestrator/PROJECT_ROUTING.md` to select specialists, references, templates, gates.
4. Mark each candidate capability include/defer/reject/investigate with reasons.
5. Create only the artifacts the risk and size justify.
6. Build in dependency order, keeping the project runnable.
7. Apply gates proportional to risk.
8. Report implemented/partial/deferred/unverified separately.
