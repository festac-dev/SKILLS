# Accessibility Remediation Playbook

1. Identify critical journeys and barriers through automated and manual evaluation.
2. Reproduce with keyboard and relevant assistive technology.
3. Prioritize by severity, frequency, and task blockage.
4. Fix semantic and interaction foundations before cosmetic adjustments.
5. Retest the complete journey, including dynamic states and errors.
6. Document remaining limitations and provide an accessible alternative where possible.
7. Prevent regressions with component guidance, tests, and review ownership.

## Application evidence

Re-run the originally blocked task through error and success with the same input method. Record automated findings separately from manual keyboard, zoom and assistive-technology results, and leave untested conformance criteria unverified.
