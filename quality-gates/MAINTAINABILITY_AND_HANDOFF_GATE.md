# Maintainability and Handoff Gate

- [ ] Setup works from a clean environment using documented steps.
- [ ] Configuration and secrets are explained without exposing real values.
- [ ] Code ownership and critical dependencies are identifiable.
- [ ] Tests, linting, formatting, and type checks are reproducible.
- [ ] Architecture and operational decisions are documented.
- [ ] Logs, dashboards, runbooks, backup, and restore are available where needed.
- [ ] Known limitations, deferred risks, and debt are explicit.
- [ ] Another competent maintainer can operate and extend the product.

## Application evidence

Check the documented entrypoint from the actual workspace and verify links immediately before handoff. Record background process ownership and stop/restart instructions without publishing secrets or machine-specific state as reusable source.
