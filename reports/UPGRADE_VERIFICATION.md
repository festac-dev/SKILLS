# Toolkit Upgrade Verification

Verified 2026-11-07. This report covers the portable SKILLS library. Application build and preview evidence belongs to the consuming project.

## Consolidation

The library contains **338 source files and 56 routes** in one directory. The previous 198-source toolkit and 318-file CLAUDE archive had 151 overlapping paths. Their current guidance was reconciled in place; 27 additional alternate paths were consolidated into canonical guides, maintenance commands or the graphics gallery. All 198 previous source paths remain present. The obsolete one-off text generator was omitted, and one merge/provenance record was added. The resulting library has 178 fewer source files than the two unmerged trees.

The [merge map](CLAUDE_MERGE_MAP.json) records source fingerprints, canonical destinations and retired paths. The source archive and recovery copies remain outside SKILLS. [Archive history](CLAUDE_IMPORT_HISTORY.md) is historical context, not the current inventory.

Existing scope, authorization, reference-analysis and motion guidance was retained. Distinct imported material includes backend patterns, infrastructure/configuration references, focused specialist resources, practical templates and runnable examples. Imported defaults and additional approval rituals do not supersede the current user brief. The catalogue, route guide and machine manifest are generated by one maintenance command.

The validator now accepts example code only in its designated directory, checks source fingerprints against the generated manifest, detects identical file content and duplicate guide titles, and rejects recreated retired paths or stale callers. Imported provenance is separate from authored-guide scenario requirements; it is not behavioral evidence.

## Motion input correction

The page-illustration guidance now defaults to scroll, viewport, pointer or automatic triggers. Unrequested play/pause buttons, step selectors, scrubbers and tuning sliders are excluded. The motion specialist owns that decision; recipes, shaders, accessibility references, templates and the quality gate no longer impose a playback toolbar. Explicitly requested media-player controls remain within their own brief.

The orbit, network and shader examples have no playback buttons; the network tuning slider was also removed. Orbit motion now uses the same visibility-aware render loop as the rest of its scene. Updated JavaScript browser checks passed automatic motion, available direct input, mobile layout, reduced-motion behavior and the shader fallback. The Python browser suite was updated for the OS preference but remains unexecuted on this host. Forty maintenance tests passed. Three additional behavioral scenarios are recorded as `not_run`; these application and example checks are not independent agent evaluations.

## Maintenance

Run `python scripts/toolkit.py index` after source changes, then `python scripts/toolkit.py validate` and the affected tests. Extend a capability in its owning guide, update callers before retiring an alternate path, and keep provenance in the merge records. Report static checks separately from actual agent behavior and product integration results.
