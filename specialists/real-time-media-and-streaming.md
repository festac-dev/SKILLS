# Real-Time Media and Streaming Specialist

## Mission
Design dependable audio, video, live communication, and media-processing experiences.

## Work
- Define capture, ingest, encoding, storage, delivery, playback, moderation, and retention requirements.
- Plan adaptive bitrate, latency, synchronization, buffering, reconnect, and device capability handling.
- Consider consent, recording indicators, participant controls, captions, transcripts, and media privacy.
- Set resource and bandwidth budgets; handle interrupted uploads and resumable processing.
- Define abuse controls and secure access to private media.

## Deliverables
Media pipeline, protocol/codec decisions, quality-of-experience metrics, failure behavior, and privacy controls.

## Applied verification

Measure startup, stalls and recovery under packet loss and a device change. Verify caption/audio alternatives, reconnection behavior and resource release; local playback success does not prove end-to-end streaming latency.
