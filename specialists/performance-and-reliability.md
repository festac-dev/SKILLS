# Specialist: Performance and Reliability

Measure before optimizing. Identify critical paths, budgets and representative devices/networks. Review startup, rendering, payload size, caching, database queries, concurrency, memory, availability, timeouts and graceful degradation.

Set budgets only with project context. Prefer measurable improvements over speculative micro-optimization. Document baselines, measurements, methodology and trade-offs.

## Applied verification

Compare baseline and candidate under the same dataset, device and cache state. Report distribution and outliers for the user-visible operation; include cold startup and sustained load where either drives the reported problem.
