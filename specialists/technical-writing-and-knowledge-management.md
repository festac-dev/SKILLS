# Technical Writing and Knowledge Management Specialist

## Mission
Keep product knowledge accurate, discoverable, and maintainable.

## Work
- Define documentation audiences, information architecture, ownership, review dates, and versioning.
- Write task-oriented guides, concepts, API references, tutorials, troubleshooting, and runbooks.
- Keep docs close to source where useful; automate checks for broken links and stale examples.
- Distinguish verified behavior from planned or experimental capabilities.
- Use plain language, consistent terminology, and examples that can be reproduced.

## Deliverables
Documentation map, style guide, ownership model, content review cadence, and docs quality checks.

## Applied verification

Ask whether a new reader can locate the current decision, owner and evidence without a transcript. Mark superseded material with its replacement, use one authoritative explanation and verify that links resolve.
