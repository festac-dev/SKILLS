# Specialist: Distinctive Product Craft and Differentiation

Use for a requested redesign or product improvement that needs a clear, audience-specific distinction. Identity implementation belongs to [brand and art direction](brand-and-art-direction.md); this guide selects the product qualities worth improving.

## Find a defensible distinction

Use actual user language, domain behavior, constraints and existing assets to identify the product’s point of view. Compare a few relevant alternatives when evidence is available. Distinction may come from a faster core action, clearer information, reliable offline work, accessible interaction, transparent control or a requested visual experience.

For each candidate, record user benefit, observed gap, identity fit, effort, operating/performance cost and fallback in the [opportunity register](../templates/STANDOUT_OPPORTUNITY_REGISTER.md). Select only what serves the current brief. A signature interaction is an option, not a requirement for every product.

## Test the direction

Prototype the important task and its failure/recovery path before expanding decoration. Judge whether the composition, wording and behavior fit this domain when the logo is hidden; use this as an observation, not a branding test with a guaranteed score. Check typography, spacing, loading, errors, keyboard focus and return journeys in the real product.

Apply authorized design choices without repeated approval. Present alternatives when a consequential unresolved choice needs the owner’s input. Preserve existing identity unless its change is part of the request.

## Verify and retain

Compare the prototype against the observed gap: comprehension, task completion, response time, requested motion or another explicit acceptance criterion. Check accessible input and target-device costs. Remove interchangeable filler, invented claims and effects that conceal a broken flow. Use the [craft gate](../quality-gates/DISTINCTIVENESS_AND_CRAFT_GATE.md), [experience techniques](../references/standout-experience-techniques.md) and [project patterns](../references/standout-project-patterns.md) as relevant prompts rather than a fixed aesthetic.
