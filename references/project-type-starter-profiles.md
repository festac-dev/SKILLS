# Project-Type Starter Profiles

Each profile lists what usually matters. It is a discovery aid, not a requirement list. Confirm with the actual brief.

## SaaS / B2B application
Auth + organizations, roles, billing/entitlements, audit log, tenant isolation, onboarding, settings, notifications, integrations/webhooks, admin console, analytics, backups, status page, data export, support tooling. Signature opportunities: workflow clarity, instant feedback, power-user speed, beautiful data views.

## Marketplace / two-sided platform
Identity and verification, listings, search, messaging, payments/escrow/payouts, reviews/reputation, dispute handling, trust and safety, fraud controls, supply and demand cold start, tax/legal review. Signature: trust cues, matching quality.

## E-commerce / checkout
Catalog, inventory, cart, pricing/tax/shipping, payments (use a PCI-conscious provider), order state machine, fulfillment, returns, email, SEO, performance, analytics, fraud checks. Signature: product presentation, speed, confident checkout.

## Content / media / publishing
CMS, editorial workflow, media pipeline, SEO, feeds, search, subscriptions/paywall, newsletters, accessibility, performance. Signature: typography, reading experience, motion that respects reading.

## Portfolio / brand / marketing site
Story, proof, performance, accessibility, SEO, contact flows, CMS or static content, analytics with privacy. Signature: one exceptional interactive or visual moment grounded in the work.

## Mobile app + backend
API, push, offline sync, auth, deep links, app store requirements, device constraints, versioning with forced upgrade path. Signature: native-feeling gestures and instant response.

## Real-time / collaborative product
WebSocket/SSE backbone, presence, conflict resolution, history, permissions, offline, scaling. Signature: sub-100 ms feedback and trustworthy sync.

## AI product / agent platform
Provider gateway, retrieval, tool permissions, evaluations, cost controls, safety, human review, logging policy. Signature: transparent reasoning/provenance and graceful failure.

## Developer platform / API product
Docs, SDKs, auth, sandbox, rate limits, webhooks, versioning, status, dashboard, usage billing. Signature: time-to-first-success under five minutes.

## Fintech / ledger
Double-entry ledger, reconciliation, idempotency, audit, KYC/AML coordination, security, regulatory review. Signature: clarity and trust.

## Healthcare-adjacent
Safety review, privacy, consent, auditability, accessibility, regulatory consultation, no clinical claims without qualified validation.

## Data / analytics product
Ingestion, modeling, quality checks, lineage, governance, dashboards, access control, cost control. Signature: understandable, trustworthy visuals.

## Game / interactive experience
Game loop, state/save systems, networking, anti-cheat, performance budgets, input systems, accessibility, live ops. Signature: feel.

## IoT / hardware
Device identity, provisioning, OTA updates, telemetry, offline behavior, security, fleet management.

## Internal tool / operations dashboard
Workflow fit, permissions, audit, integrations, bulk actions, speed, maintainability. Signature: removes real daily friction.

## CLI / TUI / developer tool
Command design, help, config, shell completion, piping behavior, error clarity, cross-platform, install path. Signature: delightful ergonomics.

## Desktop / cross-platform app
Platform conventions, updates, local storage, sync, permissions, signing/notarization, accessibility.

## Education / learning
Learning design, progress, accessibility, child-safety review where relevant, content pipeline, analytics ethics.

## Community / social
Identity, moderation, abuse prevention, notifications, feeds, privacy controls, reporting, scaling content.

## Nonprofit / civic / public-sector
Accessibility, low-bandwidth support, localization, privacy, procurement and compliance constraints, transparency.
