# Glossary (Selected)

**ACID** — atomicity, consistency, isolation, durability. **ADR** — architecture decision record. **ACME** — automatic certificate protocol. **BOLA/IDOR** — access to objects by manipulating identifiers. **CDC** — change data capture. **CRDT** — conflict-free replicated data type. **DLQ** — dead-letter queue. **FLIP** — First, Last, Invert, Play animation technique. **IaC** — infrastructure as code. **Idempotent** — repeating an operation has the same effect as doing it once. **Jitter** — randomization added to backoff. **Keyset pagination** — pagination by last-seen sort key. **Lerp** — linear interpolation. **OIDC** — OpenID Connect. **PITR** — point-in-time recovery. **RED/USE** — service and resource metric methods. **RPO/RTO** — recovery point/time objectives. **SLI/SLO/SLA** — indicator, objective, agreement. **SSRF** — server-side request forgery. **Spring** — physics-based easing defined by stiffness, damping, mass. **Stagger** — delayed sequential starts. **Vestibular trigger** — motion that can cause dizziness or nausea. **WAL** — write-ahead log.
