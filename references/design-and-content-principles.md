# Design and Content Principles

## Design for the problem, not the trend

Start with user tasks, information structure, content, constraints and context. Choose a visual language that supports those needs. Distinctiveness comes from coherent decisions, not from stacking effects.

## Neutrality and user ownership

No logo, icon, palette, font, theme, layout, material, animation, visual style or design system is mandatory. Preserve existing assets and conventions. If none exist, do not invent permanent identity elements without a reason and appropriate approval.

## Avoid generic AI aesthetics

Do not automatically add gradient blobs, floating orbs, random particles, glowing brains, meaningless globes, excessive glass, neon outlines, arbitrary 3D objects, repeated oversized rounded cards or generic dashboard grids. These are not categorically forbidden; they require a product-specific purpose and a coherent execution.

## Human language

Use familiar words, specific verbs, direct labels and useful explanations. Avoid robotic introductions, empty slogans, fake enthusiasm, buzzword stuffing, unsupported claims and repetitive copy patterns.

## Quality over decoration

Prioritize hierarchy, readability, contrast, spacing, alignment, responsive behavior, accessibility, performance and consistency. Every element should communicate, guide, enable or delight in a meaningful way.

## Design tokens

Use semantic tokens when they reduce inconsistency and improve maintainability. Derive values from the existing product system or approved direction. Avoid hard-coded values scattered through the implementation, but do not build an elaborate token framework for a tiny product.

## Motion and effects

Motion must communicate state, continuity, hierarchy or feedback. Respect reduced-motion settings and provide sensible fallbacks. Evaluate performance and input modality.

## Trust

Explain consequential actions, permissions, costs, data use and irreversible changes. Never fabricate social proof, metrics, customer logos or endorsements.

## Application evidence

An explicit request for a new visual direction authorizes reasonable local design decisions. Tie typography, spacing, hierarchy, assets and motion to the specific product, and review sibling products together when differentiation is requested. Aesthetic neutrality must not erase the user’s chosen direction.
