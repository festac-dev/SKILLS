# Input Method and Navigation Matrix

| Input | Design considerations |
|---|---|
| Touch | Target size, reach, gestures, accidental activation |
| Mouse | Hover, precision, context actions; provide alternatives |
| Keyboard | Logical focus, visible focus, shortcuts, escape behavior |
| Trackpad | Scroll/pinch and gesture conflicts |
| Stylus | Precision, palm rejection, pressure where useful |
| TV remote | D-pad focus, large targets, predictable back navigation |
| Voice | Discoverable commands, ambiguity, correction, privacy |
| Switch access | Sequential focus and semantic labels |
| Screen reader | Correct names, roles, states, announcements |
| Controller | Focus movement, mapping, remapping, feedback |

Test critical tasks with each input method relevant to the target. A device may offer several input methods; do not silently assume only one.
