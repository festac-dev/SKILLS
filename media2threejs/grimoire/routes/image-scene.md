# Image scene route

Extract spatial facts and confidence first. Establish meters/Y-up/+Z assets, room shell, landmark
observations, camera residuals, real lights, proxy layout, and relationships before standard or hero
assets. A still reference does not create a source motion track.
When the delivered camera is interactive or explorable, read and apply
`../scene/interactive_world_contract.md`; validate both the reference pose and every reachable camera
region.
