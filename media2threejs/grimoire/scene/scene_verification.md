# Scene verification

Review framing, residuals, shell topology, object presence/position/scale/relationships, palette,
light/shadows, time mapping, and side-by-side images at the selected spatial/light/action/end frames.

For interactive or explorable outputs, reference-view fidelity and exploration validity are
independent gates. Apply `interactive_world_contract.md` and include reproducible adversarial views,
camera-envelope/world-boundary evidence, path connectivity, semantic occupancy, and grounding.
