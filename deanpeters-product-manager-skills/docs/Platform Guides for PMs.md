# Platform Guides for PMs

This page helps you pick the easiest setup path for your comfort level.

Clear install and integration paths for PM teams, whatever tools you use.

If you are non-technical, start here first:
- [`Using PM Skills 101.md`](Using PM Skills 101.md)

## Quick Pick

- "I want simple chat setup" -> [`Claude Desktop`](Using PM Skills with Claude Desktop.md) or [`ChatGPT Desktop`](Using PM Skills with ChatGPT Desktop.md)
- "I can use terminal commands" -> [`Claude Code`](Using PM Skills with Claude Code.md), [`Claude /slash commands`](Using PM Skills with Slash Commands 101.md), or [`Codex`](Using PM Skills with Codex.md)
- "I need automation" -> [`n8n`](Using PM Skills with n8n.md) or [`LangFlow`](Using PM Skills with LangFlow.md)
- "I’m testing alternative stacks" -> [`OpenClaw`](Using PM Skills with OpenClaw.md)
- "I’m using Anthropic workspace tools" -> [`Claude Cowork`](Using PM Skills with Claude Cowork.md)
- "My team is building custom agents" -> [`Python agents`](Using PM Skills with Python Agents.md)
- "I use AI coding copilots" -> [`Cursor`](Using PM Skills with Cursor.md) or [`Windsurf`](Using PM Skills with Windsurf.md)
- "I use app/prototype builders" -> [`Bolt`](Using PM Skills with Bolt.md) or [`Replit Agent`](Using PM Skills with Replit Agent.md)
- "I use enterprise workflow builders" -> [`Make.com`](Using PM Skills with Make.com.md)
- "I use autonomous engineering agents" -> [`Devin`](Using PM Skills with Devin.md)
- "I run multi-agent orchestration" -> [`CrewAI`](Using PM Skills with CrewAI.md)
- "I use Google's ecosystem" -> [`Gemini`](Using PM Skills with Gemini.md)
